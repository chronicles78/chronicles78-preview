# Хроники-78 — дизайн-система Home 2.0

Эталон — архивный журнальный разворот из `assets/home-reference-exact.jpg`. Главная собирается живыми слоями, а не изображением интерфейса. Исторические материалы не подменяются сгенерированными изображениями.

## Токены

Источник — `assets/design-tokens.css`. Пока область применения ограничена `.home2` и `.home2Search`, чтобы не перекрасить существующие разделы до согласования.

| Назначение | Токены |
|---|---|
| Бумага | --paper, --paper-deep, --paper-light, --desk |
| Текст | --ink, --ink-muted, --accent |
| Линии | --line, --photo-frame |
| Материальность | --shadow-photo, --shadow-paper, --grain-opacity |
| Шрифты | --font-editorial, --font-interface, --font-handwritten |
| Иерархия | --title-size, --heading-size, --body-size, --label-size |
| Ритм | --space-1 … --space-5, --photo-border, --button-radius |
| Управление | --button-bg, --button-ink, --focus-ring |

Светлая тема: тёплая молочная бумага, глубокие синие чернила, сдержанный кирпичный акцент. Тёмная: тёмная тёплая бумага, светлые чернила, мягкие золотистые акценты; отдельные рамки, кнопки и тени. Фильтры допускаются только у фотографий и декоративного листа, не у всей страницы.

## Композиция

- Desktop: единый пропорциональный разворот 4:3 внутри viewport; поля на широких экранах сохраняют геометрию.
- Mobile: последовательное чтение тех же элементов без горизонтального скролла, доступные действия не меньше 44px. Одноэкранность требуется только desktop.
- Титул: Georgia / Times, крупная строка, аккуратные интервалы. Длинные истории используют удобную меру строки, не уменьшенный текст разворота.
- Бумага — не универсальная card: неровный край, разные поля и глубина теней. Фото имеют белую фотобумагу; отрицательные и положительные углы поворота дозированы.
- Все интерактивные элементы видимы, подписаны и получают focus-visible. Декор не перехватывает указатель и скрыт от чтения экраном.
- Состояния гостя, загрузки, пустых данных и ошибки — честные типографические вставки. Закрытый архив не отображается без авторизации.

## Будущие главы

| Раздел | Собственная композиция при общей палитре |
|---|---|
| Люди | картотека, школьный альбом, карта лиц |
| Истории | книжное оглавление, журнальная статья, удобное долгое чтение |
| Фото | архивный стол, альбом, подписи и происхождение снимков |
| Город и время | открытки, карта, газетная хроника |
| Чат | функциональный современный интерфейс, общие цвета и шрифты |
| Телевизор | самостоятельная ретро-сцена, существующий экран |
| Профиль | спокойный кабинет с ясной административной иерархией |

Остальные главы не перевёрстываются в этой задаче. После согласования Home токены подключаются по разделам с собственной композицией, проверкой чтения и регрессий.
