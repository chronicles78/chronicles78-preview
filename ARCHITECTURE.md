# Хроники-78 — архитектура

## Frontend

GitHub Pages остаётся статическим клиентом. Монолитный `index.html` разделён без смены поведения:

- `assets/app.css` — общие стили.
- `assets/js/core.js` — тема, авторизация, профиль, согласия, навигация, уведомления, главная.
- `assets/js/chat.js` — чат, вложения, реакции, realtime.
- `assets/js/people.js` — люди, коллективные фотографии, подписи лиц.
- `assets/js/stories.js` — каталог и чтение историй.
- `assets/js/photos.js` — фотоархив, пользовательские загрузки, версии и модерация фото.
- `assets/js/city.js` — «Город и время».
- `assets/js/questions-admin.js` — открытые вопросы и редакторские/административные панели.

Файлы подключаются как обычные scripts в фиксированном порядке. Общая глобальная модель пока сохранена — это намеренный промежуточный этап, чтобы не переписывать работающий сайт одновременно с рефакторингом.

## Backend

Supabase:
- Auth — passwordless e-mail + резервный парольный вход.
- Postgres — архивные сущности, чат, редакционные процессы, согласия и уведомления.
- Realtime — чат и обновления.
- Storage — рабочие изображения, исходники и pending-превью.
- Edge Functions — обработка изображений и серверная модерация.

## Фото: три слоя

1. `archive-originals` — исходник пользователя.
2. `archive-pending` — облегчённая копия заявки до решения редакции.
3. `archive-media` — рабочая оптимизированная версия, которую реально показывает сайт.

`archive_original_objects` — реестр исходников. Он отделяет логическую запись фотографии от физического места хранения оригинала.

## Google Drive — глубокий архив

Создана папка:
- «Хроники-78 — глубокий архив»
  - «Оригиналы фотографий»
  - «Резервные копии проекта»

В `archive_storage_backends` подготовлен backend `google_drive`.

Edge Function `mirror-original-to-drive` умеет:
- выбрать pending/failed оригиналы;
- скачать исходник из `archive-originals`;
- загрузить его в Google Drive;
- сохранить Drive file ID/URL в `archive_original_objects`;
- после успешного зеркалирования, только по отдельной административной команде, удалить исходник из Supabase.

По умолчанию удаление из Supabase **выключено**.

### Что нужно для включения Google Drive

В secrets Edge Functions должны быть добавлены:
- `GOOGLE_DRIVE_CLIENT_ID`
- `GOOGLE_DRIVE_CLIENT_SECRET`
- `GOOGLE_DRIVE_REFRESH_TOKEN`

OAuth должен иметь право записи в Drive пользователя. После проверки секретов `archive_storage_backends.enabled` для `google_drive` переводится в `true`.

Важно: подключение Google Drive к ChatGPT и OAuth сайта — разные контуры. Токен коннектора ChatGPT нельзя и не следует переносить в приложение.

## Следующий этап рефакторинга

Текущие JS-файлы уже физически разделены. Следующий безопасный шаг — убрать общие глобальные переменные в `window.Chronicles78` / ES modules и выделить слой доступа к данным (`api/storage/auth`) отдельно от UI. Это следует делать блоками с регрессионной проверкой, а не одним переписыванием.
