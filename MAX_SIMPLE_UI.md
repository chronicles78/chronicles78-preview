# Упрощённый интерфейс Хранителя — 25 октября 2026

По запросу Игоря уменьшено число видимых элементов.

В группе MAX новые ответы и реакции показывают только основной текст. При доступных кнопках из него убираются служебный заголовок, источник-цитаты, отметки S1 и подвал. Остаётся одна кнопка «Источники», только когда есть источники. Подсказки, примеры и ссылка на сайт не повторяются под каждым сообщением. Нажатие источников использует прежний проверенный механизм: отправляет сообщение с источником в эту же группу, где его могут увидеть все. При нескольких источниках есть кнопки переключения по их номерам; для единственного источника повторная кнопка не показывается. Старые сообщения не редактируются. При выключенных кнопках полные источники остаются в тексте, чтобы не потерять доступ к ним.

В Читальном зале поле вопроса и отправка остаются на основном экране. Поиск по словам, переключение режима и справка спрятаны под «Другие возможности». Примеры вопросов закрыты отдельно. Все источники находятся внутри одного закрытого details, затем открываются отдельные сообщения. Ссылки на документы доступны под раскрывающимся пунктом. Уведомление об обработке OpenAI остаётся видимым; восстановление запроса не изменено.

115 проверок Node и Deno check webhook/worker прошли. Проверены короткий ответ без цитат, единственная кнопка, сохранность исходных данных и проверки ссылок, экранирование, прежний режим без кнопок и восстановление результата с закрытыми источниками. Настоящее отображение в MAX и на физических телефонах после изменения отдельно не проверено. Платных запросов модели и тестовых сообщений не отправляли.

Два способа использования: обратиться к Хранителю в группе и получить общий ответ либо открыть Читальный зал и читать результат в собственном окне без автоматической публикации. Обычные личные текстовые диалоги с ботом сейчас не обрабатываются: webhook принимает одну разрешённую группу. Личный чат бота служит точкой запуска мини-приложения. Основной архив ещё не перенесён; текущая проверка относится к тестовой группе.
