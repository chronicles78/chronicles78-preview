СЕРВЕРНЫЙ ХРАНИТЕЛЬ — ПРОВЕРКА ПОИСКА И ВОПРОСЫ

Распакуйте ask-keeper.zip в Загрузки и выполните:
cd ~/Downloads/ask-keeper
bash AskKeeper.command

Введите скрыто CH78_MAX_WEBHOOK_SECRET из Supabase (не токен MAX).
Секрет не сохраняется. Локальная база на Mac вообще не читается.
Поиск и подготовка ответов выполняются в Supabase; Mac — только терминал.
Закрытие этого помощника не останавливает серверное архивирование MAX.

Сначала автоматически проверяется нахождение контрольного сообщения и
выполняется поиск по посторонней теме. OpenAI на этом этапе не вызывается.
Затем меню:
1 — обычный поиск исходных сообщений (без OpenAI);
2 — вопрос языковой модели по архиву (API может тарифицироваться);
3 — пакетная проверка: пять готовых вопросов, до десяти платных вызовов API;
Enter — завершить работу.

В режиме 3 вопросы вводить не нужно. Проверяются три содержательные темы
(караоке, певческий опыт, уточнение о Шанхае) и два отказа при отсутствии
достаточных сведений. Программа проверяет источники и ссылки, но не доказывает
достоверность каждого утверждения. Итог и ответы выводятся в терминал.
Ошибка сети или провайдера останавливает пакет без повторных запросов.

Например, сначала найдите: дискотека
Затем попробуйте вопрос: Что вспоминали о школьных дискотеках?
Если материалы — только технические тесты или не содержат ответа,
правильное поведение — честно сообщить о нехватке сведений.

Ответ включает ссылки [S1] и далее. Под ним показаны реальные сообщения,
авторы и даты по Самаре. Проверка ссылок не гарантирует правильности
интерпретации моделью: сверяйте факты с источниками. Из-за ограничения
объёма часть длинного текста может быть сокращена; это явно отмечается.
Ответы в MAX не публикуются. Все результаты видит только оператор терминала.

21.10.2026 владелец подтвердил ответ OpenAI через серверную функцию.
Полнота поиска и точность содержательных ответов проверяются отдельно.
При ошибке сообщите только строку статуса; секрет не присылайте.
Автоматических повторов нет: сетевой тайм-аут после отправки не означает,
что провайдер не обработал запрос. Ожидание ответа — до 140 секунд.
Не включайте запись терминальной сессии и не отправляйте скриншоты с ключами.

Сертификаты проверяются. При необходимости используется ранее созданный
~/Downloads/ch78-openai-ca.pem с корневыми сертификатами macOS.
Перенаправления запрещены. Секрет передаётся только заданному Supabase HTTPS
endpoint в заголовке; он не включается в URL или тело запроса.

Локальные проверки клиента: python3 -B -m unittest -v test_client.py
Тесты выполняются без настоящих секретов, сети и платных API.
Серверные проверки: 31 тест + GitHub Actions; живые SQL-поиск и закрытые
права проверены. Владелец подтвердил работу клиента на Mac и один ответ через OpenAI.
