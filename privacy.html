Хроники-78 — архив фотографий · редакция от 30 сентября 2026 года

Назначение проекта и контакт

«Хроники-78» — закрытый электронный архив выпускников. Администрация и редакция используют данные для работы архива, общения участников и сохранения общей истории. По вопросам данных обращайтесь через «Профиль → Приватность» или по адресу WhiteCarol8069@outlook.com.

Какие данные обрабатываются

Адрес электронной почты для входа, имя и сведения профиля, класс или группа, фотографии и подписи, сообщения, истории, комментарии, вопросы и другие материалы, предоставленные участниками. Система также сохраняет сведения о согласии, правах доступа и действиях, необходимых для модерации и работы архива.

Внутренняя статистика посещений

Для понимания востребованности проекта и работы чата архив фиксирует время посещения, открытые основные разделы сайта, тип устройства, грубое обозначение платформы и активность в чате. Для вошедшего участника эти сведения могут быть связаны с его профилем и доступны администратору во внутренней панели посещаемости.

Для посетителя без входа используется случайный анонимный идентификатор сессии. Проект не сохраняет IP‑адрес посетителя для этой статистики и не создаёт цифровой fingerprint устройства. Полный User-Agent браузера в журнал посещений не записывается.

Кто получает доступ

Материалы архива предназначены для зарегистрированных участников. Редакторы и администраторы обрабатывают загрузки и обращения в пределах своих полномочий. Согласие участника на использование данных внутри архива не разрешает отдельную открытую публикацию его фотографий и ФИО.

Сервисы хранения

Интерфейс размещён на GitHub Pages. Для учётных записей, базы данных, файлов и серверных функций используется Supabase. При включении внешнего архивирования оригиналы фотографий передаются в Google Drive аккаунта, подключённого владельцем хранилища. Эти сервисы обрабатывают данные в рамках своей работы; их серверы могут находиться за пределами страны пользователя.

Доступ к данным Google

Владелец хранилища отдельно разрешает доступ через Google OAuth. Запрашиваемое разрешение https://www.googleapis.com/auth/drive технически позволяет приложению читать, создавать, изменять и удалять файлы Google Drive. Это широкое разрешение, а не ограничение доступа одной папкой на стороне Google.

Назначение интеграции — копирование оригиналов в настроенную архивную папку и проверка сохранённых копий. Для этого приложение передаёт содержимое и имена файлов, читает их идентификаторы, размеры, контрольные суммы и расположение. В базе архива сохраняются идентификатор внешнего файла, ссылка, состояние копирования и служебные сведения. Просмотр посторонних документов владельца не является функцией архива.

OAuth-реквизиты и токен обновления используются серверной частью для доступа без повторного входа владельца. Они не предназначены для публикации в коде сайта или передачи участникам. Отключить разрешение можно в настройках Google-аккаунта: подключения к сторонним приложениям. Это остановит дальнейший доступ приложения, но само по себе не удалит уже сохранённые копии.

Использование и передача данных Google

Данные Google используются только для описанной функции архивного хранения. Они не продаются, не используются для рекламы, оценки кредитоспособности или обучения общих моделей искусственного интеллекта. Доступ к ним предоставляется только для работы этой функции, решения обращений владельца, обеспечения безопасности либо исполнения применимых требований закона.

Использование и передача информации, полученной через Google API, осуществляются в соответствии с Google API Services User Data Policy, включая требования Limited Use.

Срок хранения и удаление

Журнал посещаемости предназначен для внутренней статистики проекта; детальная административная панель показывает в основном последние 30 дней. Материалы архива сохраняются для ведения архива до обращения об удалении, отзыва согласия или прекращения проекта. Обращения рассматривает администратор; удаление не происходит автоматически в момент отправки запроса. В запросе можно указать конкретные фотографии, записи и внешние копии. Остаточные копии могут сохраняться в резервных архивах до их плановой замены или удаления.

При включении переноса оригиналов удаление исходного файла из Supabase предусматривается только после проверки внешней копии и отдельного включения этой операции администратором. Рабочая облегчённая версия фотографии может оставаться на сайте.

Защита и изменения политики

Для ограничения доступа используются авторизация и роли участников. Браузер хранит данные сеанса, необходимые для входа. Не сообщайте другим лицам ссылки входа и секретные реквизиты. При изменении практики обработки данных эта страница обновляется; существенное изменение условий согласия требует отдельного подтверждения участника.
